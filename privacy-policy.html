🛡️ Résumé : Arabic Kids est une application éducative destinée aux enfants. Nous ne collectons aucune donnée personnelle identifiable. La confidentialité et la sécurité de vos enfants sont notre priorité absolue.

1. Introduction

Arabic Kids ("l'Application") est une application mobile éducative qui aide les enfants à apprendre la langue arabe de manière ludique. Cette politique de confidentialité explique comment nous traitons les informations lors de l'utilisation de l'Application.

2. Public cible

L'Application est conçue pour les enfants, sous la supervision de leurs parents ou tuteurs légaux. Elle est conforme aux exigences du RGPD (UE), de la loi COPPA (États-Unis) et du programme "Designed for Families" de Google Play.

3. Données collectées

3.1 Données stockées localement

Les informations suivantes sont stockées uniquement sur l'appareil de l'utilisateur :

  • Prénom de l'enfant (saisi par le parent) — utilisé uniquement pour l'affichage dans l'app
  • Avatar choisi (un emoji)
  • Code d'accès (4 chiffres) — stocké localement pour protéger le profil
  • Progression : score, niveau, lettres apprises, badges gagnés
  • Préférences : langue de l'interface, niveau de difficulté
Ces données ne sont jamais transmises à nos serveurs et restent exclusivement sur l'appareil.

3.2 Données collectées automatiquement

L'Application utilise les services tiers suivants :

  • Google Firebase Analytics : collecte des données d'utilisation anonymes (écrans visités, quiz complétés, temps d'utilisation). Aucune donnée personnelle identifiable n'est collectée. Politique Firebase
  • Google AdMob : affiche des publicités interstitielles adaptées à l'âge (non personnalisées pour les enfants). Politique AdMob

3.3 Données NON collectées

Nous ne collectons jamais :

  • Adresse e-mail, numéro de téléphone ou adresse postale
  • Données de géolocalisation
  • Photos, vidéos ou contacts
  • Identifiants de connexion à des réseaux sociaux

4. Microphone

L'Application demande l'accès au microphone uniquement pour la fonctionnalité de lecture à voix haute (reconnaissance vocale arabe). L'audio est traité localement par le système Android et n'est jamais enregistré ni transmis.

5. Publicité

L'Application affiche des publicités via Google AdMob. Pour les utilisateurs identifiés comme enfants :

  • Les publicités ne sont pas personnalisées
  • Le remarketing est désactivé
  • Seules des publicités adaptées à l'âge sont affichées

6. Partage de données

Nous ne vendons, ne louons et ne partageons aucune donnée personnelle avec des tiers. Les seules données transmises sont les analytics anonymes via Firebase et les requêtes publicitaires via AdMob.

7. Sécurité

Toutes les données de l'enfant (profil, progression) sont stockées localement sur l'appareil via le stockage sécurisé du navigateur WebView (localStorage). Aucune transmission réseau de données personnelles n'est effectuée.

8. Droits des parents

Les parents ont le droit de :

  • Consulter les données de leur enfant dans l'application
  • Supprimer le profil de l'enfant en désinstallant l'application (supprime toutes les données locales)
  • Contacter le développeur pour toute question

9. Conservation des données

Les données locales sont conservées tant que l'application est installée. La désinstallation de l'application supprime définitivement toutes les données.

10. Modifications

Nous nous réservons le droit de modifier cette politique. Les utilisateurs seront informés des changements significatifs via une mise à jour de l'application.

11. Contact

Pour toute question concernant cette politique de confidentialité :

📧 hsr.consultin.pro@gmail.com

🛡️ Summary: Arabic Kids is an educational app for children. We do not collect any personally identifiable information. Your children's privacy and safety are our top priority.

1. Introduction

Arabic Kids ("the App") is an educational mobile application that helps children learn the Arabic language in a fun way. This privacy policy explains how we handle information during the use of the App.

2. Target Audience

The App is designed for children, under the supervision of their parents or legal guardians. It complies with GDPR (EU), COPPA (US), and Google Play's "Designed for Families" program requirements.

3. Data Collected

3.1 Data Stored Locally

The following information is stored only on the user's device:

  • Child's first name (entered by the parent) — used only for display within the app
  • Chosen avatar (an emoji)
  • Access code (4 digits) — stored locally to protect the profile
  • Progress: score, level, letters learned, badges earned
  • Preferences: interface language, difficulty level
This data is never transmitted to our servers and remains exclusively on the device.

3.2 Automatically Collected Data

The App uses the following third-party services:

  • Google Firebase Analytics: collects anonymous usage data (screens visited, quizzes completed, usage time). No personally identifiable information is collected. Firebase Privacy
  • Google AdMob: displays age-appropriate interstitial ads (non-personalized for children). AdMob Policy

3.3 Data NOT Collected

We never collect:

  • Email address, phone number, or postal address
  • Geolocation data
  • Photos, videos, or contacts
  • Social media login credentials

4. Microphone

The App requests microphone access only for the read-aloud feature (Arabic speech recognition). Audio is processed locally by the Android system and is never recorded or transmitted.

5. Advertising

The App displays ads via Google AdMob. For users identified as children:

  • Ads are not personalized
  • Remarketing is disabled
  • Only age-appropriate ads are displayed

6. Data Sharing

We do not sell, rent, or share any personal data with third parties. The only data transmitted is anonymous analytics via Firebase and ad requests via AdMob.

7. Security

All child data (profile, progress) is stored locally on the device via the secure WebView browser storage (localStorage). No network transmission of personal data is performed.

8. Parental Rights

Parents have the right to:

  • Review their child's data within the application
  • Delete their child's profile by uninstalling the app (deletes all local data)
  • Contact the developer with any questions

9. Data Retention

Local data is retained as long as the application is installed. Uninstalling the application permanently deletes all data.

10. Changes

We reserve the right to modify this policy. Users will be notified of significant changes via an app update.
