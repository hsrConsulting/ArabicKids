📌 VERSION 1.4.0 — Premium revampé, hub Quiz, tracé pixel-perfect
─────────────────────────────────────

🇫🇷 Français :
• Nouveau scoring du tracé basé sur le glyphe réel : marche automatiquement pour toutes les lettres
• Tracés ajustés pour د، ذ، ر، ز (lettres non-connecteurs)
• Page Premium refondue : comparaison Gratuit vs Premium claire, plan annuel mis en avant, zéro pub pour les abonnés
• Tous les quiz regroupés dans une seule tuile « 🎯 Quiz » avec catégories (Lettres / Mots / Sons / Jeux / Premium)
• Module Mots : prononciation TTS avec tanwīn ḍamm automatique (« qalamun » au lieu de « qalam »)
• Correctif navigation : retour depuis Inscription/Connexion va à l'accueil (au lieu du dashboard non-authentifié)
• Dashboard simplifié : 19 → 12 tuiles

🇬🇧 English:
• New tracing scorer based on the actual glyph mask — auto-adapts to every letter
• Adjusted trace paths for د، ذ، ر، ز (non-connector letters)
• Premium screen redesigned: clear Free vs Premium comparison, yearly plan highlighted, zero ads for subscribers
• All quizzes grouped under a single "🎯 Quiz" tile with categories (Letters / Words / Sounds / Games / Premium)
• Words module: TTS now applies tanwīn ḍamm automatically ("qalamun" instead of "qalam")
• Navigation fix: back from Register/Login returns to Welcome (was incorrectly going to dashboard)
• Simplified dashboard: 19 → 12 tiles

🇸🇦 العربية:
• خوارزمية تقييم جديدة للخط مبنية على الشكل الحقيقي للحرف — تتكيف تلقائيًا مع كل حرف
• تعديل مسارات الكتابة لـ د، ذ، ر، ز
• إعادة تصميم شاشة Premium: مقارنة واضحة بين المجاني والمدفوع، إبراز الخطة السنوية، لا إعلانات للمشتركين
• تجميع كل الاختبارات في تبويب واحد "🎯 اختبار" مع تصنيفات (حروف / كلمات / أصوات / ألعاب / Premium)
• قسم الكلمات: نطق tanwīn ḍamm تلقائيًا ("قَلَمٌ" بدل "قَلَم")
• تصحيح التنقل: العودة من التسجيل/الدخول إلى صفحة الترحيب
• لوحة تحكم مبسطة: 19 → 12 تبويبًا

📌 VERSION 1.3.1 — Correctif tracé des lettres
─────────────────────────────────────

🇫🇷 Français :
• Évaluation du tracé plus exigeante : sous 30% de correspondance, message d'encouragement sans validation
• Seuils d'étoiles relevés (50% pour 2⭐, 70% pour 3⭐) pour mieux valoriser l'effort
• Bouton "Réessayer" intégré dans l'écran de résultat

🇬🇧 English:
• Stricter tracing evaluation: under 30% match shows an encouragement message with no validation
• Higher star thresholds (50% for 2⭐, 70% for 3⭐) to better reward effort
• "Try again" button integrated in the result card

🇸🇦 العربية:
• تقييم أصعب للخط: أقل من 30% تطابق يعرض رسالة تشجيع دون اعتماد
• رفع عتبات النجوم (50% للنجمتين، 70% للثلاث نجوم) لتقدير الجهد بشكل أفضل
• زر "أعد المحاولة" مدمج في بطاقة النتيجة


📌 VERSION 1.3.0 — Chasse aux lettres, histoires avancées
─────────────────────────────────────

🇫🇷 Français :
• Nouvelle activité « Chasse aux lettres » : repère toutes les occurrences d'une lettre dans une phrase
• 3 mots-exemples supplémentaires pour chaque lettre (plus de vocabulaire)
• Compteur de maîtrise par lettre (vues, écoutes, chasses réussies)
• 2 nouvelles histoires pour le niveau avancé (forêt enchantée, voyage en montagne) avec questions de compréhension
• Son sur sukun et shadda désormais correctement prononcés
• Quiz d'association : tu peux commencer par le mot français ou arabe, moins de rafraîchissements
• Bouton « Terminer le défi » sur le défi du jour
• Changements de contenu : lion pour Alif, plume pour Ra, retrait de certains mots et animaux peu pertinents
• Corrections de prononciation (ثُعْبَانٌ, سُلْحُفَاة) et d'icônes

🇬🇧 English:
• New "Letter hunt" activity: tap every occurrence of a letter in a sentence
• 3 additional example words per letter (more vocabulary exposure)
• Per-letter mastery counter (views, listens, hunts won)
• 2 new advanced-level stories (enchanted forest, mountain trip) with comprehension questions
• Sukun and Shadda now speak correctly
• Match quiz: you can start from the French or Arabic side, fewer refreshes
• "Complete challenge" button on the daily challenge
• Content update: lion for Alif, feather for Ra, removed a few less relevant words/animals
• Pronunciation fixes (ثُعْبَانٌ, سُلْحُفَاة) and icon fixes

🇸🇦 العربية:
• نشاط جديد "صيد الحروف": المس كل موضع يظهر فيه الحرف في جملة
• 3 أمثلة كلمات إضافية لكل حرف (مفردات أكثر)
• عدّاد إتقان لكل حرف (مرات المشاهدة والاستماع وفوز الصيد)
• قصتان جديدتان للمستوى المتقدم (الغابة الساحرة، رحلة الجبل) مع أسئلة فهم
• السكون والشدة يُنطقان الآن بشكل صحيح
• اختبار المطابقة: يمكنك البدء من الكلمة الفرنسية أو العربية، تحديثات أقل
• زر "إنهاء التحدي" في تحدي اليوم
• تحديث المحتوى: أسد للألف، ريش للراء، إزالة بعض الكلمات/الحيوانات الأقل أهمية
• تصحيحات النطق (ثُعْبَانٌ، سُلْحُفَاة) والأيقونات
