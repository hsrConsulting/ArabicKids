     ✅ CHECKLIST DE PUBLICATION — ARABIC KIDS SUR GOOGLE PLAY
══════════════════════════════════════════════════════════════


📌 ÉTAPE 1 : COMPTE GOOGLE PLAY DEVELOPER
──────────────────────────────────────────
☐ Créer un compte sur https://play.google.com/console/
☐ Payer les frais d'inscription (25$ USD, une seule fois)
☐ Vérifier votre identité (peut prendre 48h)


📌 ÉTAPE 2 : PRÉPARER LES ASSETS (ce dossier)
───────────────────────────────────────────────
☐ Icône 512x512 (exporter depuis le projet)
☐ Feature Graphic 1024x500 (créer avec Canva/Figma)
☐ Minimum 2 screenshots téléphone (voir screenshots/GUIDE)
☐ Screenshots tablette (recommandé)
☐ Descriptions FR/EN/AR (voir dossier textes/)
☐ Politique de confidentialité publiée en ligne (URL publique)


📌 ÉTAPE 3 : CONFIGURATION DE L'APP (Play Console)
───────────────────────────────────────────────────
☐ App name : Arabic Kids - Apprends l'arabe
☐ Default language : Français (ou Anglais)
☐ App type : Application
☐ Free / Paid : Gratuite
☐ Category : Education
☐ Email de contact : [votre email]


📌 ÉTAPE 4 : FICHE STORE (Store Listing)
─────────────────────────────────────────
☐ Titre (30 car. max)
☐ Description courte (80 car. max)
☐ Description complète (4000 car. max)
☐ Icône de l'app (512x512)
☐ Feature Graphic (1024x500)
☐ Screenshots téléphone (min 2)
☐ Ajouter les traductions (EN, AR) si souhaité


📌 ÉTAPE 5 : CLASSIFICATION DU CONTENU
───────────────────────────────────────
☐ Remplir le questionnaire IARC (voir questionnaire-classification-contenu.txt)
☐ Résultat attendu : PEGI 3 / Everyone


📌 ÉTAPE 6 : PUBLIC CIBLE ET CONTENU
─────────────────────────────────────
☐ Tranche d'âge cible : cocher "5-8 ans" et "8-12 ans" (ou custom 4-10)
☐ L'app est-elle destinée aux enfants ? → OUI
☐ L'app contient-elle des publicités ? → OUI
☐ Les pubs sont-elles conformes aux Families Ads ? → OUI
☐ Politique de confidentialité : renseigner l'URL


📌 ÉTAPE 7 : SÉCURITÉ DES DONNÉES (Data Safety)
────────────────────────────────────────────────
☐ L'app collecte-t-elle des données ? → OUI (via AdMob)
☐ Device identifiers : Collecté (AdMob)
☐ Partagé avec des tiers : OUI (Google pour les pubs)
☐ Données chiffrées en transit : OUI
☐ Suppression possible : OUI (désinstallation)


📌 ÉTAPE 8 : CONFIGURATION TECHNIQUE
─────────────────────────────────────
☐ Remplacer les IDs AdMob test par les vrais IDs de production :
   - AndroidManifest.xml : APPLICATION_ID
   - MainActivity.java : INTERSTITIAL_AD_UNIT_ID
☐ Changer le mot de passe du keystore (actuellement 'arabickids2024')
☐ Mettre à jour build.gradle si le mot de passe change


📌 ÉTAPE 9 : UPLOAD DU BUILD
─────────────────────────────
☐ Fichier AAB : app/build/outputs/bundle/release/app-release.aab
☐ Aller dans Release > Production > Create new release
☐ Uploader le fichier .aab
☐ Ajouter les notes de version (voir notes-de-version.txt)
☐ Google Play App Signing : accepter (recommandé)


📌 ÉTAPE 10 : REVUE ET PUBLICATION
───────────────────────────────────
☐ Vérifier tous les avertissements dans "Publishing overview"
☐ Soumettre pour revue
☐ Délai de revue : généralement 1-3 jours (peut aller jusqu'à 7 jours)
☐ Vous recevrez un email quand l'app sera approuvée
