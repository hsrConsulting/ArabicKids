📌 EXIGENCES GOOGLE PLAY
─────────────────────────
• Format : JPEG ou PNG 24 bits (pas d'alpha/transparence)
• Dimensions : min 320px, max 3840px, ratio max 2:1
• Téléphone : minimum 2, maximum 8 screenshots
• Tablette 7"  : recommandé (minimum 2 si fournis)
• Tablette 10" : recommandé (minimum 2 si fournis)

📌 COMMENT PRENDRE LES SCREENSHOTS
────────────────────────────────────

Option A — Depuis l'émulateur Android Studio :
1. Lancez l'app dans l'émulateur
2. Naviguez vers l'écran souhaité
3. Cliquez sur l'icône caméra dans la barre d'outils de l'émulateur
4. Sauvegardez dans ce dossier

Option B — Depuis un appareil physique :
1. Installez l'APK : adb install app-release.apk
2. Naviguez vers l'écran souhaité
3. Bouton Power + Volume Bas pour capturer
4. Transférez les captures sur votre PC

Option C — Via ADB :
   adb shell screencap /sdcard/screenshot.png
   adb pull /sdcard/screenshot.png ./01-dashboard.png


📌 CONSEILS POUR DES SCREENSHOTS ATTRACTIFS
────────────────────────────────────────────
• Utilisez un profil avec de la progression (quelques badges, score)
• Montrez des données réalistes (pas un profil vide)
• Prenez les screenshots sur un écran haute résolution (1080x1920 min)
• Assurez-vous que la barre de statut est propre (WiFi, batterie pleine)
• Vous pouvez ajouter du texte promotionnel autour des screenshots
  avec des outils comme Canva, Figma, ou App Screenshot Maker
